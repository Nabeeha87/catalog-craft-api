# 🛍️ Product Catalog API

A simple RESTful API for managing a product catalog using Node.js, Express, and MongoDB.

---

## 🚀 Features

* Add, view, update, delete products
* Search by name or category
* Pagination support
* MongoDB integration

---

## 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose

---

## ⚙️ Setup

```bash id="x91kpl"
npm install
npm run dev
```

---

## 📡 API Endpoints

* GET /api/products
* POST /api/products
* PUT /api/products/:id
* DELETE /api/products/:id
